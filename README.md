# Shadrack Maingi | Cybersecurity Portfolio

This repository contains a personal cybersecurity portfolio website built with HTML and CSS.

## Project purpose
This portfolio is designed to showcase:
- cybersecurity skills and training
- work experience and internships
- certifications and learning achievements
- project work and lab experience
- contact details for professional networking

## Files
- `index.html` — main portfolio landing page
- `styles.css` — website styling and responsive layout
- `cv.html` — CV/resume page

## Preview locally
Open the project folder in a browser, or run a local server from the project directory:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment
This site can be deployed using GitHub Pages or any static hosting provider.
